# typewriter-duo-ios

Public pages for **Platen Writer**, the vintage typewriter app for iPhone and iPad,
served by GitHub Pages:

- Support: https://aswathhasinasyed.github.io/typewriter-duo-ios/support/
- Privacy policy: https://aswathhasinasyed.github.io/typewriter-duo-ios/privacy/

The contact email is set once, in `_config.yml`.

To publish: Settings › Pages › Build and deployment › Source: **Deploy from a branch**,
Branch: **main**, folder **/ (root)**.
